# Global-Internet-Usage-Analysis
Interactive Power BI dashboard analyzing global internet usage trends using the World Bank World Development Indicators (WDI) dataset.
Project Overview

This project analyzes global internet usage using the World Bank World Development Indicators (WDI) dataset. The dashboard explores internet adoption across countries and trends over time using Microsoft Power BI.

# Dataset

World Bank World Development Indicators (WDI)

Indicator Used:

Individuals using the Internet (% of population)

# Tools Used

Microsoft Power BI
Power Query
DAX
World Bank WDI Dataset

# Dashboard Features

Highest Internet Usage
Average Internet Usage
Lowest Internet Usage
Total Countries
Internet Usage Trend Over Time
Top 10 Countries by Internet Usage
Average Internet Usage by Country
Country and Year Slicers

# Key Insights

Internet usage has grown significantly over the years.
Several developed countries consistently report internet penetration above 90%.
Large differences exist between countries in internet adoption.
Interactive filters allow comparison across countries and years.
